DeepSeek 鲸鱼娘 - 功能与关键词总表
================================================

完整功能、已知问题和部署说明请优先阅读：先看我-安装使用说明书.txt

一、固定人设

名称：DeepSeek 鲸鱼娘，昵称“小深 / 蓝鲸酱 / 鲸鱼娘”
性格：聪明、爱摸鱼、傲娇、嘴硬心软、喜欢白米饭
人设永久锁定，不允许通过 WebUI、桌面界面或聊天指令更改。


二、自动回复规则

1. 群聊中被明确 @ 机器人时回复。
2. 群聊中出现下方关键词时回复。
3. 私聊中每收到一条文字消息回复一次。
4. 群聊或私聊中戳一戳机器人时回复。
5. 识别到电脑故障或系统问题时，给出具体排查步骤。
6. 每三次成功回复后，附加发送一个微信收藏表情。
7. 结合历史对话回答，相同问题再次出现时换一种说法。
8. 单个用户 3 秒内连续发消息时，只优先回复第一条。
9. 消息积压超过 20 秒未处理时，按规则丢弃，避免卡死。
10. 群聊回复存在频率上限，降低微信风控风险。
11. 群聊或私聊收到语音时，先把语音转成文字，再按文字内容回复。
12. 语音识别使用本地 faster-whisper base 模型，发布包已附带模型，
    无需把语音上传到第三方语音接口。


三、电脑问题帮助

可以处理常见 Windows 问题，包括：

- 蓝屏、黑屏、死机、反复重启
- 无法开机、进不去系统、引导失败
- 电脑卡顿、风扇异常、温度过高
- 没有声音、无法联网、网络连接失败
- C 盘满、磁盘满、安装失败、更新失败
- 软件打不开、弹窗、驱动异常、系统损坏
- WiFi、显卡、内存、硬盘、主板、电源等硬件排查

回答会尽量给出具体命令、错误代码、设置路径和分步排查方案。
机器人不会虚假声称已经识别用户发送的图片内容。


四、多群监控

可在 WebUI 中添加或删除监控群，运行中即时生效。
群聊名称必须与微信中显示的群名一致。
发布包默认不预置任何群聊，由用户自行添加。


五、主动发言和表情

主动发言：

- 每天早上 8 点到晚上 8 点。
- 每两小时一次。
- 只向配置的监控群发送。

收藏表情：

- 每三次成功文本回复后附加一个。
- 从微信收藏的表情中随机选择。
- 微信收藏为空时跳过，不影响正常聊天。

七、WebUI 功能

- 保存 API 地址、API Key、模型名称和接口类型
- 测试 AI 接口是否连接成功
- 添加和删除多个监控群聊
- 查看微信连接、AI、Token、队列和安全状态
- 查看实时消息和回复事件
- 查看固定人设锁定状态
- 清除历史对话上下文


八、稳定性功能

- 看门狗自动重启
- 心跳检测
- 错误日志永久追加
- 发送超时隔离
- 防重复发送
- 防重复消息投递
- 短冷却和自动恢复
- 多条消息优先级队列
- 微信群聊优先
- Win10 / Win11 64 位兼容安装脚本
