微信鲸鱼娘机器人 - 先看我 - 安装使用说明书
================================================

适用系统
--------
Windows 10 / Windows 11 64 位。

本项目包含微信、QQ 官方机器人、企业微信、WebUI、桌面界面、本地语音识别、
多群监控、定时主动发言、收藏表情、看门狗防崩溃、
错误日志和密钥加密等功能。

固定人设
--------
DeepSeek 鲸鱼娘，昵称“小深 / 蓝鲸酱 / 鲸鱼娘”。
性格设定为聪明、爱摸鱼、傲娇、嘴硬心软、喜欢白米饭。
人设已经被配置、桌面界面和 Web API 锁定，发布包不提供修改入口。


一、第一次使用，按顺序操作
--------------------------

1. 把整个压缩包解压到固定目录，例如：

   D:\鲸鱼娘

   不要直接在压缩包里面运行，也不要放在临时目录或会被同步软件自动删除的位置。

2. 双击：

   一键安装所有依赖.bat

   这个脚本会自动尝试：
   - 安装 Python 3.12
   - 创建项目专用 .venv
   - 安装核心依赖
   - 安装微信 3.9.x 可选兼容依赖
   - 安装本地语音识别和 ffmpeg 依赖
   - 检查核心模块是否可以导入

   首次安装需要联网，通常需要几分钟。

3. 用户自行打开并登录微信桌面客户端。
   机器人只连接已经登录且可见的微信窗口，不负责扫码登录。

4. 双击：

   一键启动机器人-防崩溃.bat

   这个脚本会调用 start.bat，由 supervisor.py 看门狗启动机器人。
   机器人崩溃、无响应、心跳停止时，看门狗会自动重启。

5. 浏览器打开：

   http://127.0.0.1:8080/

   在 WebUI 中填写：
   - API 地址或 Base URL
   - API Key
   - 模型名称
   - 接口类型

   然后点击“保存配置”和“测试 API”。

6. 在 WebUI 的群聊监控区域添加需要监听的微信群名称。
   群名必须与微信中显示的群名一致。

7. 如果使用 QQ 官方机器人，在 WebUI 的 QQ 页签填写 AppID、AppSecret，
   保存后启动 QQ 端。

8. 如果使用企业微信，在 WebUI 的企微页签填写 bot_id 和 secret。
   凭证无效时该平台会显示 error，不会影响已经配置好的其它平台。


二、推荐的文件和用途
--------------------

先看我-安装使用说明书.txt
    功能总表、安装步骤、已知问题和排查方法。建议所有用户先看这个文件。

给AI的一键部署指令.txt
    可直接发给 WorkBuddy、Codex、ChatGPT 或其它 AI，让它按固定步骤部署。

一键安装所有依赖.bat
    推荐的一键安装入口。

一键启动机器人-防崩溃.bat
    推荐的启动入口。调用看门狗，崩溃后自动恢复。

一键启动网页控制台.bat
    只启动 WebUI 控制台，不自动启动机器人平台。

安装开机自启-防崩溃.bat
    可选。在 Windows 当前用户的启动目录创建快捷方式，登录后自动启动防崩溃版本。

卸载开机自启.bat
    删除上一步创建的开机自启快捷方式。

start.bat
    旧名称，仍然可用。负责清理旧进程并启动看门狗。

restart-clean.bat
    清理旧进程后重新启动，适合端口占用或进程卡死时使用。

setup.bat
    底层安装脚本，通常不需要直接运行。

AI自动部署说明.txt
    AI 或技术人员使用的手动部署说明。

使用说明.txt
    原有的简短使用说明，保留以兼容旧用户。

功能与关键词.txt
    原有功能与关键词总表，保留以兼容旧用户。

config.yaml
    运行配置。发布包中的 API 地址、API Key、模型默认都是空的。


三、当前已经可用的功能
----------------------

1. 固定鲸鱼娘人设
   可用。人设不能被 WebUI、桌面界面、配置文件或聊天提示词修改。

2. 微信 AI 聊天
   可用，但用户必须先打开并登录微信桌面客户端，且主窗口保持可见。

3. QQ 官方机器人
   可用。需要在 WebUI 中填写有效的 AppID 和 AppSecret。

4. 企业微信
   代码和 WebUI 配置入口可用，但必须有有效的 bot_id 和 secret。
   发布包不附带有效凭证。

5. WebUI 控制台
   可用。支持查看状态、实时消息、平台状态、API 配置、语音配置、曲库、
   群聊添加删除、上下文清除、QQ 凭证配置和企业微信凭证配置。

6. AI 接口
   可用。兼容 DeepSeek、OpenAI 兼容接口和大多数中转站接口。
   地址、密钥、模型可以在 WebUI 中保存，不需要修改源码。

7. 对话上下文
   可用。程序会保存群聊和私聊上下文，AI 回复时参考最近消息。
   重复问题会检测历史答案，并尝试换一种说法回答。

8. 群聊监控
   可用。支持一个或多个微信群，WebUI 中可以添加和删除群聊。

9. 群聊 @ 回复
   可用。群聊中明确 @ 机器人后触发回复。

10. 关键词回复
    可用。关键词命中后触发回复，关键词完整列表见本说明第六部分。

11. 私聊回复
    可用。私聊收到文本后按规则回复。

12. 戳一戳 / 拍一拍
    可用。群聊和私聊均可触发本地回复。
    同一用户 3 秒内只回复第一条戳一戳。

13. 用户突发消息冷却
    可用。单用户 3 秒内连续发多条时，只优先回复第一条。

14. 过期消息沉默
    可用。配置中 max_message_age 默认为 600 秒。
    单条消息超过 10 分钟还没有被处理时会丢弃，避免过晚回复。

15. 群聊优先级
    可用。消息队列针对群聊、私聊和普通聊天设置了优先级。

16. 语音识别
    可用。支持微信和 QQ 语音。
    本地 faster-whisper base 模型随发布包附带。
    当前版本已经修复 QQ 将 SILK 文件错误命名为 .amr 的问题，
    会根据文件头识别真实的 SILK 编码。

17. 图片识别
    当前版本明确关闭。
    收到图片时不会分析图片内容，也不会自动搜索或发送图片，
    只会把“[图片]”作为上下文占位。
    这是为了避免机器人假装识别图片或给出错误结论。

18. 电脑问题回答
    可用。常见 Windows 问题会走较长回答模式，例如蓝屏、无法联网、
    磁盘满、驱动异常、软件打不开、系统更新失败等。

19. 三次回复附加收藏表情
    可用。每三次成功回复后，尝试从微信收藏表情中随机选择一个发送。
    收藏为空或平台不支持时不会影响普通文字回复。

20. 群聊定时主动发言
    可用。默认每天 8:00 到 20:00 之间每 2 小时一次。
    只向已配置的监控群或主动发言群发送。

21. 看门狗防崩溃
    可用。supervisor.py 会检测进程退出、心跳停止和桥接端口异常，
    并按指数退避自动重启。

22. 永久错误日志
    可用。错误会追加到 logs\errors.log，不覆盖、不主动删除。
    每次启动会写入 START 分隔标记，便于定位最后一次启动的问题。

23. 发送恢复
    可用。微信发送超时或短时失败时，会等待并尝试恢复发送。

24. API Key 加密
    可用。WebUI 保存密钥后，程序会使用 Fernet 加密后写入配置。

25. 发布包防泄漏
    可用。发布包构建时会检查 API Key 和已知中转站地址，
    发布版 config.yaml 中 API 地址、密钥和模型默认为空。


四、需要满足条件才能使用的功能
------------------------------

1. 微信端
   需要用户自行安装、登录并保持微信主窗口可见。
   微信未启动时 WebUI 会显示 wechat.status=error，这不是崩溃。

2. QQ 官方机器人
   需要官方机器人平台开关、权限和有效凭证。
   某些机器人账号没有群聊权限，只能使用私聊。

3. 企业微信
   需要正确的企业微信机器人 bot_id 和 secret。

4. 语音识别
   需要本地模型目录 data\models\faster-whisper\base 完整。
   发布包已经附带模型；如果没有附带或目录缺失，首次启动会尝试从
   hf-mirror.com 下载。


五、已知问题和限制
------------------

1. “2 秒内回复”是优化目标，不是绝对保证。
   AI 接口、模型、网络、QQ/微信窗口响应慢时，总耗时会超过 2 秒。

2. QQ 富媒体上传可能返回 HTTP 400。
   这通常与 QQ 官方机器人权限、上传接口限制或账号能力有关。
   文字回复不受影响；语音或文件可能发送失败。

3. 当前运行环境曾出现企业微信 access_token 获取失败。
   原因通常是 bot_id、secret 不正确，或者企业微信后台没有开启对应权限。

4. 微信自动化需要微信主窗口可见。
   最小化、系统锁屏、微信更新弹窗或窗口被其它程序遮挡时，可能连接或发送失败。

5. 图片识别不启用。
   收到图片时不会分析图片内容，也不会自动搜索或发送图片。
   如果用户希望解决图片里的电脑问题，可以提示用户把错误代码或
   现象打成文字发送。

6. 收藏表情依赖微信收藏和 UI Automation。
   收藏为空、微信窗口不可控或自动化后端不支持时，表情会跳过。
   收藏表情只在当前打开的聊天窗口发送，不会切换窗口。

7. 定时主动发言只在配置了群聊时生效。
   没有配置监控群或主动发言群时，不会主动发送。

8. 发布包不包含真实 API Key、微信聊天记录或用户缓存数据。

9. 使用微信自动化工具存在账号风控风险。
   建议使用测试账号，控制回复频率，不要短时间内大量发送。

10. 本项目仅针对 Windows 10 / Windows 11 64 位。
    没有验证 Linux、macOS、手机系统或 Windows 32 位。

八、日志和故障排查
------------------

logs\chatbot.log
    聊天、连接、回复和普通运行日志。

logs\supervisor.log
    看门狗启动、退出、超时和自动重启记录。

logs\errors.log
    永久追加错误日志。查找问题时优先搜索最近的“=== START ===”。

logs\console.log
    机器人控制台输出的追加记录。

logs\crash.log
    Python 原生崩溃堆栈。

logs\unhandled.log
    未捕获异常。

runtime\bot.heartbeat
    看门狗使用的心跳文件。

建议排查顺序：

1. 打开 logs\errors.log，搜索最后一次“=== START ===”。
2. 查看 START 后的第一条 ERROR 和完整堆栈。
3. 查看 logs\supervisor.log 是否反复重启或提示心跳超时。
4. 确认微信已经登录、窗口可见、版本受支持。
5. 在 WebUI 中点击“测试 API”。
6. 检查网络、代理、API 余额、模型名称和 Base URL。
7. 语音识别失败时检查 data\models\faster-whisper\base 是否完整。
8. QQ 语音上传失败时先检查机器人平台的富媒体权限。


九、停止和重新启动
------------------

- 正常关闭机器人窗口可以停止桌面程序。
- 看门狗会在崩溃或无响应时自动重启机器人。
- 需要彻底重启时，双击 restart-clean.bat。
- 不要同时启动多个 start.bat，否则多个进程会争抢微信窗口。
- 不要直接结束 supervisor.py；结束它会导致没有人负责自动重启。


十、给 WorkBuddy 或其它 AI 的部署方式
------------------------------------

如果安装脚本执行失败，可以把下面的文件交给 AI：

给AI的一键部署指令.txt
AI自动部署说明.txt

WorkBuddy、Codex、ChatGPT 或其它可以操作电脑的 AI 应先阅读
“先看我-安装使用说明书.txt”，再按照“给AI的一键部署指令.txt”
执行。AI 不得替用户填写 API Key，不得修改固定人设，不得开启图片识别，
不得删除 logs\errors.log。

只有用户明确要求时，才安装开机自启。
