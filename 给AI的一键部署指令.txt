微信鲸鱼娘机器人 - 给 WorkBuddy 或其它 AI 的一键部署指令
================================================

把本文件和整个项目目录一起交给 WorkBuddy、Codex、ChatGPT 或其它
可以读写文件和执行命令的 Windows AI。

可以直接复制下面这段提示词：

------------------------------------------------

你是 Windows 10/11 部署助手。请在我解压后的微信鲸鱼娘机器人目录中
完成本地部署。先阅读以下文件：

1. 先看我-安装使用说明书.txt
2. AI自动部署说明.txt
3. requirements.windows.txt
4. requirements.wxauto3.txt

然后按顺序执行：

1. 确认系统是 Windows 10 或 Windows 11 64 位，当前目录包含 main.py、
   supervisor.py、requirements.windows.txt。
2. 双击或命令行运行“一键安装所有依赖.bat”。
3. 如果该脚本失败，按 AI自动部署说明.txt 手动安装 Python 3.12、
   创建 .venv、安装 requirements.windows.txt。
4. 验证以下模块能导入：
   PySide6、fastapi、uvicorn、httpx、yaml、cryptography、loguru、
   PIL、psutil、win32api、wechatauto、wxauto4、faster_whisper、pysilk。
5. 运行：
   .\.venv\Scripts\python.exe -m py_compile main.py supervisor.py web_main.py
6. 运行：
   .\.venv\Scripts\python.exe tests\test_dual_platform.py
   如果测试文件存在，必须看到“全部通过”或“测试结束：全部通过”。
7. 启动“一键启动机器人-防崩溃.bat”，确认 supervisor.py 正在运行。
8. 打开 http://127.0.0.1:8080/ ，确认首页和 /api/status 可以访问。
9. 不要替用户填写 API Key。提醒用户在 WebUI 中填写 API 地址、密钥、
   模型，并点击“测试 API”。
10. 不要修改或覆盖固定人设 tsundere_whale_girl。
11. 不要开启图片识别。图片识别在当前版本是明确关闭的功能。
12. 不要删除 logs\errors.log。排查问题时按最近的“=== START ===”
    标记往后看。
13. 不要一次性启动多个 start.bat。需要重启时运行 restart-clean.bat。
14. 只有用户明确要求开机自动启动时，才运行“安装开机自启-防崩溃.bat”。
15. 最后报告：
    - Python 和 .venv 路径
    - 依赖安装结果
    - 测试结果
    - WebUI 地址
    - 微信、QQ、企业微信平台状态
    - 仍然存在的错误或需要用户手动处理的步骤

执行约束：

- 保留已有 config.yaml，不覆盖用户数据。
- 不把真实 API Key 写入文件、日志或最终回答。
- 不隐藏错误，不伪造测试成功。
- 遇到失败时先查看 logs\errors.log、logs\supervisor.log、
  logs\console.log，再决定如何修复。
- 所有命令都应在解压后的项目根目录执行。

------------------------------------------------

没有 AI 操作权限时，可以让用户手动按“先看我-安装使用说明书.txt”
的第一次使用步骤操作。
