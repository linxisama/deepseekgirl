微信聊天机器人 - 便携安装说明
================================

一、目标电脑要求

1. Windows 10 或 Windows 11，64 位系统。
2. 安装 Python 3.12，安装时勾选 “Add Python to PATH”。
3. 安装微信 4.x 桌面版；微信登录由用户自行完成，机器人只连接已登录窗口。
4. 首次安装依赖需要联网。

Python 下载地址：
https://www.python.org/downloads/windows/


二、安装步骤

1. 把整个 鲸鱼娘 文件夹解压到一个固定目录。
   建议路径不要经常移动，例如：
   D:\鲸鱼娘

2. 双击 setup.bat。
   脚本会自动创建 .venv 并安装依赖。

3. 安装结束后会自动打开 config.yaml。
   至少填写：
   ai.api_key: "你的 API Key"
   如有需要，修改：
   ai.api_url
   ai.model
   wechat.target_groups

4. 保存 config.yaml，然后双击 start.bat。
5. 在机器人窗口中点击“启动机器人”。


三、只使用网页控制台

双击 start-web.bat，然后访问：
http://127.0.0.1:8080

不显示命令行窗口时，可以双击 start-web-hidden.vbs。


四、注意事项

1. 安装包不包含 API Key，避免密钥泄露。
2. 不要直接把当前电脑的 config.yaml 发给别人，里面可能包含密钥。
3. 人设已永久锁定为“傲娇鲸鱼娘”，不能通过界面和 Web 修改。
4. 微信自动化存在账号风控风险，建议先使用测试账号。
5. 如果依赖安装很慢，可以配置 pip 国内镜像后重新运行 setup.bat。


五、常见问题

问题：提示未找到 Python 3.12。
处理：安装 Python 3.12，并勾选 Add Python to PATH，然后重新运行 setup.bat。

问题：提示找不到微信窗口。
处理：由用户登录微信桌面版，保持主窗口可见，不要最小化，然后重新启动机器人。

问题：机器人没有回复。
处理：群里必须明确 @ 机器人昵称；检查 API Key、API URL、模型名和网络。

问题：随机表情没有发送。
处理：确认微信收藏中至少有一个表情；首次发送会等待 10 到 20 分钟。
