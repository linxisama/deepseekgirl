微信鲸鱼娘机器人 - 使用说明
================================================

完整版说明书请优先阅读：先看我-安装使用说明书.txt
推荐的一键安装脚本：一键安装所有依赖.bat
推荐的防崩溃启动脚本：一键启动机器人-防崩溃.bat

一、首次使用

1. 解压整个压缩包到固定目录，例如 D:\鲸鱼娘。
2. 双击“一键安装所有依赖.bat”。
3. 安装完成后，双击 start-web.bat 或 start.bat。
4. 浏览器访问 http://127.0.0.1:8080/
5. 在网页中填写 API 地址、API Key 和模型名称。
6. 点击“保存配置”，再点击“测试 API”。
7. 添加需要监控的微信群名称。
8. 保持已登录的微信主窗口可见。


二、发布包中的关键文件

一键安装所有依赖.bat 自动安装 Python 3.12 和全部依赖
start.bat          启动桌面机器人和看门狗
start-web.bat      仅启动网页控制台
start-web-hidden.vbs  无命令行窗口启动网页控制台
config.yaml        空白配置，API 地址、密钥和模型默认留空
AI自动部署说明.txt  安装脚本失败时供 AI 或技术人员自动部署
功能与关键词.txt    当前机器人全部功能和触发关键词


三、日常使用

- 群聊中明确 @ 机器人后回复。
- 私聊中每收到一条消息回复一次。
- 群聊或私聊中收到语音时，会先转成文字再结合上下文回复。
- 群聊或私聊中戳一戳机器人会触发回复。
- 关键词出现时自动回复。
- 每三次成功回复后，附加一个收藏表情。
- 每天早上 8 点到晚上 8 点，每两小时主动发一次群消息。


四、修改配置

推荐直接在 WebUI 修改，不需要编辑代码。

API 地址可以填写：

- DeepSeek 的完整接口地址
- OpenAI 兼容中转站的完整接口地址
- 中转站提供的 Base URL

模型名称必须填写接口实际支持的名称。人设“傲娇鲸鱼娘”已永久锁定，
不能在 WebUI、桌面界面或配置中被改成其它人设。

语音识别默认使用发布包内附带的本地 base 模型，不需要单独填写语音 API。
如果 data\models\faster-whisper\base 不存在，首次启动会尝试通过
hf-mirror.com 自动下载，下载期间文字聊天仍可正常使用。


五、停止和重启

- 正常关闭机器人窗口即可停止桌面程序。
- 看门狗会在程序崩溃或无响应时自动重启。
- 需要彻底重启时，双击 restart-clean.bat。
- 不要同时启动多个 start.bat，否则多个进程会争抢微信窗口。


六、注意事项

1. 机器人不负责微信登录，只连接用户已经登录的微信窗口。
2. 微信自动化存在账号风控风险，建议降低回复频率或使用测试账号。
3. 发布包不包含真实 API Key，也不会代替用户填写密钥。
4. 如果安装或启动失败，先阅读 AI自动部署说明.txt 和 logs\errors.log。
